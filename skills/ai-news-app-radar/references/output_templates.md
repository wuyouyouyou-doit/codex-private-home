# Output Templates

## A) 每日简报条目模板

```markdown
### {{中文标题}}
- 事实摘要：{{1-2句客观事实}}
- 关键细节：
  - {{细节1：主体 + 动作 + 时间}}
  - {{细节2：关键数字/里程碑}}
  - {{细节3：范围/对象/限制条件}}
- 影响解读：{{对产业链、应用落地或竞争格局的影响}}
- 观点对照：
  - 来源A（{{媒体名}}）：{{观点A}}
  - 来源B（{{媒体名}}）：{{观点B}}
- Links：
  - {{URL1}}
  - {{URL2}}
```

## B) 应用雷达模板

```markdown
### {{案例名/公司名}}

- 成熟度：{{概念验证/试点/规模化}}

```
